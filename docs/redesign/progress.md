| P2.06 | 2026-11-12 | 6 h (including review and fixes) | `ferrispass-cli run --id UUID --secret-fd N:FIELD -- <program>` hands a program the password, the one-time code or a protected field of an entry on a descriptor, so the secret is never in a file, on the command line or in the environment. `--env NAME=FIELD` puts it into one variable instead, as an explicit fallback with a warning.
